# Pawsitive Pet Academy

Website and mobile app for **Pawsitive Pet Academy**, a fictional pet training academy. Built for the XHAW5112 Work Integrated Learning (WIL) module at Varsity College.

## Repository layout

| Folder | What it is |
| --- | --- |
| `group-website/` | The group website (HTML/CSS pages), merged in with full commit history |
| `group-mobile-app/` | The group mobile app (Android Studio / Gradle project), merged in with full commit history |
| `Website/` | Earlier manual copy of the website files (legacy) |
| `PawsitiveApp/` | Earlier manual copy of the mobile app (legacy) |
| `.github/` | GitHub config (Dependabot) |

> The `group-*` folders are the source of truth. `Website/` and `PawsitiveApp/` can be removed once confirmed identical.

## Website

Static site. Pages include:

- About Us
- Contact Us
- Details page
- Fees calculator
- Summary page

**Run it:** open any page in `group-website/pages/` in a browser, or serve the folder with a local server (for example the VS Code Live Server extension).

## Mobile app

Android project built with Gradle.

**Run it:**

1. Open `group-mobile-app/` in Android Studio.
2. Let Gradle sync.
3. Run on an emulator or a connected device.

## History
