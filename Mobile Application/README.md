# Pawsitive Pet Academy — Mobile App

A React Native (Expo) build of the Pawsitive Pet Academy app, matching the
final design decisions from the group's Task 1 workbook: the Cream /
Powder Blue / Tan colour palette, the recoloured dog badge logo, and all
six low-fidelity screens (Splash, Home, About, Courses, Course Detail,
Pricing / Fees Calculator, Contact).

This matches the tooling the group already chose in **Phase H –
Infrastructure Planning**: React Native + Expo, tested with the Android
Studio Emulator or the Expo Go app.

## Running it

You'll need [Node.js](https://nodejs.org) installed (v18 or newer).

```bash
npm install
npx expo install --fix   # aligns native module versions with your Expo SDK
npx expo start
```

This opens the Expo developer tools in your terminal/browser. From there you can:

- Press **`a`** to open in a connected Android emulator (Android Studio).
- Press **`i`** to open in the iOS simulator (macOS + Xcode only).
- Scan the QR code with the **Expo Go** app on your own phone — fastest way
  to see it on a real device.
- Press **`w`** to open it in a web browser (Expo also supports exporting
  the same codebase to the web via `react-native-web`, if you want a second
  way to preview it without a simulator).

## Project structure

```
App.js                     Navigation container (Stack navigator)
src/theme.js                Colours + font roles (mirrors the website)
src/data/courses.js         Course content, pricing & discount logic
src/components/Header.js    Shared header: logo + burger nav menu
src/screens/
  SplashScreen.js
  HomeScreen.js
  AboutScreen.js
  CoursesScreen.js
  CourseDetailScreen.js
  PricingScreen.js          Fees calculator ("Your Cart")
  ContactScreen.js
assets/                     App icon, splash screen, logo (generated by
                             generate_assets.py — safe to regenerate or
                             replace with the final Figma exports)
```

## Notes

- The fees calculator applies the group's discount structure: 2 courses =
  5% off, 3 courses = 10% off, 4+ courses = 15% off, shown against a
  running subtotal/discount/total — matching the "Fees Calculator" and
  "Your cart" wireframes.
- "Get My Quote" does not process real payment — it mirrors the
  **quote-not-transaction flow** described in the workbook (Sarah's team
  follows up to confirm payment via card, Apple Pay, Google Pay or EFT).
- Fonts: native platforms don't ship Book Antiqua / Arial Narrow / Calibri,
  so `src/theme.js` maps each brand font role to the closest built-in
  system font per platform. Swap in custom `expo-font` loading later if you
  want pixel-exact brand fonts.
- The dog badge logo in `assets/` is a placeholder redrawn to match the
  finalised palette — swap in the actual Figma/PNG export whenever it's
  ready, keeping the same file names.
